========================================
HOW TO RUN THE SQL SCRIPT
========================================

STEP 1: Open phpMyAdmin
------------------------
1. Open your web browser
2. Go to: http://localhost/phpmyadmin
3. Login with your MySQL credentials

STEP 2: Select Your Database
-----------------------------
1. Look at the left sidebar
2. Click on your database name (probably: u348045755_test5)

STEP 3: Run the SQL Script
---------------------------
1. Click the "SQL" tab at the top of the page
2. Open the file: update_departments.sql (in this folder)
3. Copy ALL the content from that file
4. Paste it into the SQL query box in phpMyAdmin
5. Click the "Go" button at the bottom right

STEP 4: Verify It Worked
-------------------------
After running the script, run these queries to verify:

Query 1 - Check departments:
SELECT * FROM departments;

Query 2 - Check students have departments:
SELECT id, user_id, department_id, current_semester FROM students;

Query 3 - Check subjects have departments:
SELECT id, subject_code, subject_name, semester, department_id FROM subjects;
